# Test vectors

Published input and output vectors for the report merge, for configuration resolution, for the template rendering, for the SARIF rendering and for the baseline live here, one directory per case under `merge/`, `config/`, `template/`, `sarif/` and `baseline/`. Each case holds its inputs and the exact expected output, so an implementation is tested against declared data rather than against another implementation. The merge algorithm the vectors exercise is the one `contract/grammar/merge.md` states, the template language the one `contract/grammar/template.md` states, the SARIF mapping the one `contract/grammar/sarif.md` states and the baseline the one `contract/grammar/suppression.md` states.
